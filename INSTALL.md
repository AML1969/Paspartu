# Установка Паспарту — пошагово (для Windows 11)

Это подробная инструкция «делай раз-два-три». Паспарту — личный Telegram-ассистент,
который ты запускаешь **на своём компьютере** внутри Docker. Управление — перепиской с ботом в Telegram.

> ⏱️ Времени: ~30–40 минут (большая часть — автоматическая сборка).
> 💻 Нужно: Windows 11, ~15 ГБ свободного диска, стабильный интернет.

---

## Шаг 0. Подготовь ключи (5–10 минут) — ДО установки

Открой Telegram и браузер, собери в блокнот 3 обязательные вещи:

1. **Токен Telegram-бота.** В Telegram напиши боту **@BotFather** → команда `/newbot` → придумай имя
   и юзернейм бота → BotFather пришлёт строку вида `8123456789:AAH...` — это **токен**, сохрани.
2. **Свой Telegram ID** — это число, по которому ассистент поймёт, что пишешь именно ты (и будет
   слушать только тебя). Как его узнать через бота **@userinfobot**:
   - В Telegram нажми **поиск 🔍** вверху и введи `userinfobot`.
   - В результатах выбери бота **@userinfobot** (проверь, что юзернейм точно такой — бывают похожие подделки).
   - Открой его и нажми кнопку **Start** внизу (или отправь сообщение `/start`).
   - Бот сразу ответит твоими данными, например:
     ```
     Id: 123456789
     First: Иван
     Username: @ivan
     ```
   - Скопируй **число после `Id:`** (только цифры, без `@` и без букв) — это и есть твой Telegram ID. Сохрани его.
   - Не нашёлся или не отвечает? Подойдёт альтернатива — бот **@getmyid_bot** (так же `/start` → пришлёт `Your user ID`).

   > Это число понадобится на Шаге 3 в ответе на вопрос мастера **«Твой Telegram ID»**.
3. **Ключ DeepSeek** (это «мозг», обязателен). Зарегистрируйся на <https://platform.deepseek.com>,
   раздел API keys → создай ключ `sk-...`. Сохрани. (DeepSeek дешёвый, пополни баланс на пару $.)

Необязательные ключи (можно добавить позже, для расширений):
- **fal.ai** (<https://fal.ai>) — генерация картинок Qwen-Image и редактирование фото
  (ключ формата `key_id:key_secret`; заметно дешевле OpenAI).
- **OpenAI** (<https://platform.openai.com>) — распознавание присланных изображений (vision);
  может и рисовать (gpt-image-2), если ключа fal.ai нет.
- **Perplexity** (<https://www.perplexity.ai/settings/api>) — умный веб-поиск.

> Без необязательных ключей всё равно всё работает — соответствующие функции просто выключатся сами.

## Шаг 1. Поставь Linux + Docker на Windows (один раз)

Паспарту работает в Linux-контейнере. На Windows проще всего через **WSL2** (это лёгкий Linux внутри Windows).

1. Открой **PowerShell от имени администратора** и выполни:
   ```powershell
   wsl --install
   ```
   Перезагрузи компьютер. После перезагрузки откроется окно **Ubuntu** — придумай в нём имя пользователя и пароль.

2. Поставь **Docker Desktop for Windows**: <https://www.docker.com/products/docker-desktop>.
   При установке оставь включённым **«Use WSL 2 based engine»**. После установки запусти Docker Desktop,
   зайди в **Settings → Resources → WSL Integration** и включи переключатель для своей **Ubuntu**.

3. (Рекомендуется) Дай WSL2 побольше памяти. В Windows создай файл `C:\Users\<ТЫ>\.wslconfig` с содержимым:
   ```ini
   [wsl2]
   memory=6GB
   ```
   Затем в PowerShell: `wsl --shutdown` (применится при следующем запуске Ubuntu).

4. Проверь, что всё готово — **в окне Ubuntu** выполни:
   ```bash
   docker compose version
   ```
   Должно вывести `Docker Compose version v2.x`. Если так — отлично, идём дальше.

> Альтернатива WSL2 — обычная виртуалка (VirtualBox/VMware) с Ubuntu и установленным внутри Docker.
> Тогда все шаги ниже выполняй внутри этой Ubuntu. Дай ВМ **≥4 ГБ RAM и ≥15 ГБ диска**.

## Шаг 2. Скачай Паспарту

**Важно:** всё делай **внутри Ubuntu** (в домашней папке `~`), а не в `C:\...` — так быстрее и без ошибок.

```bash
cd ~
git clone https://github.com/AML1969/Paspartu.git
cd Paspartu
```

## Шаг 3. Запусти мастер установки

```bash
./install.sh
```

Мастер задаст вопросы — отвечай по порядку:

| Вопрос мастера | Что вводить |
|---|---|
| **Имя копии** | латиницей, без пробелов, напр. `petrov` (просто метка этой установки) |
| **Telegram bot token** | токен из @BotFather (Шаг 0.1) |
| **Твой Telegram ID** | число из @userinfobot (Шаг 0.2) |
| **DeepSeek API key** | ключ `sk-...` (Шаг 0.3) |
| **Профиль** | набери **`2`** (standard) — рекомендуемый набор |
| **Провайдер картинок** | **Enter** (авто: ключ fal.ai → Qwen, иначе OpenAI → GPT, иначе выкл). Потом можно сменить строкой `IMAGE_PROVIDER=QWEN\|GPT\|NONE` в `copies/<имя>.env` + перезапуск |
| **Ключ OpenAI / Perplexity / fal.ai** | вставь, если есть; если нет — **просто нажми Enter** (функция выключится) |

> 📌 **«Имя копии» — это название твоей установки, которое ты придумываешь сам** (латиницей, без пробелов,
> например `petrov`). **Запомни его!** Дальше во всех командах там, где написано `<имя>`, нужно подставлять
> именно это название — и **без угловых скобок** `<>`. Пример: назвал `ivan` → вместо `./run-copy.sh <имя>`
> пишешь `./run-copy.sh ivan`.

Профили на выбор:
- **1 — minimal**: мозг + Telegram + веб-поиск + память. Самый лёгкий.
- **2 — standard** *(рекоменд.)*: minimal + банк памяти + картинки + голос + Google + трекер задач.
- **3 — full**: всё из standard (Codex в этой версии не входит).
- **4 — custom**: включить/выключить каждый блок вручную.

Ключи проверяются сразу при вводе (при ошибке — повтор); после ответов мастер соберёт образ и запустит бота. **Первая сборка идёт несколько
минут** (скачивается ~3 ГБ) — это нормально, просто подожди.

> 💡 Только ключ DeepSeek и больше ничего? Выбери профиль `1` и жми Enter на остальных ключах —
> получишь рабочего ассистента (чат + Telegram + память), а картинки/поиск просто будут отключены.

## Шаг 4. Проверь, что бот ожил

Подставь своё имя копии вместо `<имя>`:

```bash
COPY=<имя> docker compose -p bif-<имя> ps
```
**Пример** для копии `petrov`: `COPY=petrov docker compose -p bif-petrov ps`

В колонке **STATUS** должно быть `Up`/`running` (а не `Restarting`/`Exited`).

Затем **открой своего бота в Telegram и напиши `/start`** — он должен ответить. 🎉

Посмотреть логи (если что-то не так), выход по `Ctrl+C`:
```bash
COPY=<имя> docker compose -p bif-<имя> logs -f hermes
```

## Шаг 5 (по желанию). Подключить Google — почта/календарь/диск

Только если выбрал профиль с Google. Кратко (подробности — в README, раздел «Google»):
1. В Google Cloud создай OAuth-клиент типа **Desktop**, включи нужные API (Gmail/Calendar/Drive/Docs/Sheets).
2. **Обязательно** опубликуй приложение: **Publish app → In production** (иначе доступ отвалится через 7 дней).
3. Положи `client_secret.json` в контейнер и напиши боту «настрой Google Workspace» — он пришлёт ссылку,
   открой её в браузере, вставь код обратно в чат.

## Если что-то пошло не так

| Симптом | Причина и решение |
|---|---|
| Бот молчит, контейнер в `Restarting` | Смотри логи (Шаг 4). Чаще всего — неверный ключ (`401`/`Unauthorized`) → перепроверь: `./install.sh --check <имя>` |
| `docker: command not found` | Docker Desktop не запущен или WSL-интеграция выключена (Шаг 1.2) |
| Сборка падает на скачивании | Нет интернета/блокировка. Нужен доступ к PyPI, Docker Hub, `deb.nodesource.com` |
| Мало места / «no space left» | Освободи диск (нужно ~15 ГБ) или увеличь диск ВМ |
| Бот «тормозит» / падает по памяти | Дай WSL2/ВМ ≥4 ГБ RAM (Шаг 1.3) |
| `bash: ./install.sh: ...^M` | Клонировал на Windows, а не в Ubuntu — клонируй внутри `~` (Шаг 2) |

Перезапустить копию вручную (когда `.env` уже создан) — `<имя>` замени на своё (напр. `petrov`):
```bash
./run-copy.sh <имя>        # например: ./run-copy.sh petrov
```

Обновиться до новой версии:
```bash
git pull
./run-copy.sh <имя>        # например: ./run-copy.sh petrov
```
