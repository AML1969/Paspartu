# Паспарту 🗝️ — личный AI-ассистент в Telegram

> 🐧 **Эта ветка `linux` — установка на чистый Ubuntu / Linux-сервер.**
> Ставишь на Windows 11 (через WSL2)? — ветка **`main`**:
> <https://github.com/AML1969/Paspartu/tree/main>

Паспарту — твой персональный ассистент на базе Hermes Agent, который живёт **на твоём компьютере**
в Docker, а общаешься ты с ним перепиской в **Telegram**. Никаких чужих серверов: ключи и данные
остаются у тебя.

## Что умеет

- 💬 **Общение и помощь** — мозг на DeepSeek (умный и дешёвый).
- 🔎 **Веб-поиск** — актуальные факты, цены, новости (Perplexity / встроенный поиск).
- 🖼️ **Картинки** — генерация и распознавание изображений (с ключом OpenAI).
- 🎙️ **Голос** — понимает голосовые сообщения (локальное распознавание).
- 🧠 **Память** — помнит факты и заметки между сессиями (банк памяти + поиск).
- 📄 **Документы** — делает **DOCX, PDF и презентации `.pptx`**, кладёт на Google Диск.
- 📬 **Google** — почта, календарь, диск, документы, таблицы (после подключения).
- ✅ **Задачи** — трекер задач и напоминания.

## 🚀 Быстрый старт

На Linux (или Ubuntu в WSL2 на Windows) с установленным Docker:

```bash
git clone -b linux https://github.com/AML1969/Paspartu.git && cd Paspartu
./install.sh
```

Мастер сам всё спросит, соберёт и запустит. **Заранее подготовь:** токен Telegram-бота (@BotFather),
свой Telegram ID (@userinfobot) и ключ DeepSeek.

> 📘 **Не уверен, с чего начать? → [Подробная инструкция: INSTALL.md](INSTALL.md)**
> — пошагово, с нуля, специально для Windows 11 (как поставить Linux+Docker, что отвечать мастеру,
> как проверить, что делать при ошибках).

## Что нужно (требования)

- **Ubuntu/Debian** — сервер/VPS или машина с Linux. Пошагово — [INSTALL.md](INSTALL.md).
- **Docker** + плагин `docker compose` v2. Проверка: `docker compose version`.
- **~4 ГБ RAM и ~15 ГБ свободного диска** (образ ~3 ГБ + том с данными).
- **Интернет** (исходящий HTTPS). Telegram работает «наружу» — **пробрасывать порты не нужно.**

## Возможности по профилям

При установке выбираешь профиль — набор включённых функций:

| Профиль | Что входит |
|---|---|
| **minimal** | мозг + Telegram + веб-поиск + память |
| **standard** *(рекоменд.)* | minimal + банк памяти + картинки + голос + Google + трекер задач |
| **full** | всё из standard |
| **custom** | включить/выключить каждый блок вручную |

Функции, для которых не дал ключ, **выключаются сами** — например, только с ключом DeepSeek получишь
рабочего ассистента без картинок и платного поиска. Никаких ошибок из-за отсутствующих ключей.

## Проверка после установки

```bash
COPY=<имя> docker compose -p bif-<имя> ps        # STATUS должен быть Up / running
COPY=<имя> docker compose -p bif-<имя> logs -f hermes   # логи (Ctrl+C — выход)
```
Затем напиши боту в Telegram `/start` — он должен ответить. Подробнее и решение проблем — в [INSTALL.md](INSTALL.md).

## Управление

```bash
./run-copy.sh <имя>      # перезапустить/пересобрать копию
git pull && ./run-copy.sh <имя>   # обновиться до новой версии
./install.sh --check <имя>        # перепроверить ключи
```

Несколько копий на одной машине не пересекаются — каждая поднимается под своим именем
(`-p bif-<имя>`), со своим томом данных. Секреты хранятся только в `copies/<имя>.env` на твоём
диске — **никогда** не в образе и не в git.

## Документы, PDF и презентации

В образ встроен офис-стек (`pandoc` + `libreoffice` + `pptxgenjs`), поэтому Паспарту умеет:
- **DOCX / PDF** — превращает текст/анализ в оформленный документ и кладёт на Google Диск.
- **Презентации `.pptx`** — создаёт и редактирует слайды, рендерит в PDF.

> Нативные Google Slides не поддерживаются — презентации делаются как `.pptx` и заливаются на Google
> Диск (Google сам открывает/конвертирует их). Google Docs/Sheets/Gmail/Calendar/Drive — напрямую.

## Google — подключение (по желанию)

1. В Google Cloud создай OAuth-клиент типа **Desktop**, включи нужные API (Gmail/Calendar/Drive/Docs/Sheets).
2. **Обязательно** опубликуй приложение: **Publish app → In production** (иначе доступ отвалится через 7 дней).
3. Положи `client_secret.json` в контейнер и пройди авторизацию через бота:
   ```bash
   COPY=<имя> docker compose -p bif-<имя> cp ./client_secret.json hermes:/data/hermes/client_secret.json
   ```
   Затем напиши боту «настрой Google Workspace» — он пришлёт ссылку, открой её в браузере на своём
   компьютере, а полученный код вставь обратно в чат. Токен сохранится и переживёт перезапуски.

## Как это устроено (для технарей)

Docker-образ `bif:1.0` собирается из `python:3.12-slim`: ставится `hermes-agent==0.16.0` (+ extras
`messaging`/`voice`/`vision`/`google`, `ddgs`, `markitdown`) и офис-стек, на build-time накатываются
8 патчей формата сообщений (rich/локализация). Архитектура **блочная** — лишнее выключается тумблерами
`WITH_*` в `copies/<имя>.env`; конфиг под выбранные блоки правится автоматически при первом запуске.

```
Paspartu/
  Dockerfile            # образ: hermes-agent 0.16.0 + extras + офис-стек + патчи
  install.sh            # интерактивный мастер (+ режимы --headless, --check)
  run-copy.sh           # пересборка/перезапуск копии из готового .env
  entrypoint.sh         # первичная раскладка по тумблерам WITH_*
  docker-compose.yml    # сервис hermes (+ профили codex/site)
  secrets.env.example   # шаблон .env для ручной установки
  copies/               # <имя>.env каждой копии (в .gitignore, секреты только тут)
  seed/                 # конфиг, шаблоны SOUL/AGENTS, скиллы, патчи
```

Ручная установка без мастера:
```bash
cp secrets.env.example copies/petrov.env
$EDITOR copies/petrov.env && chmod 600 copies/petrov.env
COPY=petrov docker compose -p bif-petrov up -d --build
```

**Примечания версии 1.0:**
- Образ собран и проверен на arm64 (сборка, накат патчей, генерация PDF/`.pptx`); на amd64 все
  зависимости тоже доступны — первая реальная amd64-сборка происходит у тебя при установке.
- Codex (тяжёлые фоновые задачи) в эту версию **не входит** — в compose это пустой плейсхолдер.
