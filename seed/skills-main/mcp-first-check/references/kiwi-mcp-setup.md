# Kiwi MCP — справка (main-бот, Docker)

## Где это работает
Контейнер `paspartu-andrew` (образ `paspartu:2.x`, Hermes 0.19).
Пакет `mcp` установлен в образ: **mcp 1.26.0**, `/usr/local/lib/python3.12/site-packages`.
Отдельно ничего ставить НЕ нужно.

⚠️ НЕ выполнять `pip install mcp --break-system-packages` и вообще не ставить mcp руками:
установка в чужое окружение — исходная причина поломки Kiwi (июль 2026). Если пакет
действительно пропал, это признак того, что контейнер собран не из того образа —
сказать владельцу, а не доустанавливать на живом.

## Конфиг (уже прописан)

    mcp_servers:
      kiwi:
        url: https://mcp.kiwi.com
        timeout: 180
        connect_timeout: 60

Файл: `/root/.hermes/config.yaml` внутри контейнера (на хосте —
`/root/paspartu-andrew-data/hermes/config.yaml`).

## Инструмент

`mcp__kiwi__search_flight` — откуда/куда (город или код IATA), даты с гибкостью ±3 дня,
класс, пассажиры (взрослые/дети/младенцы), в одну сторону или туда-обратно.
Возвращает отобранные варианты с прямыми ссылками на бронирование.
Также доступен `mcp__kiwi__feedback_to_devs`.

## Проверка

    hermes mcp list           # kiwi должен быть ✓ enabled
    hermes mcp test kiwi      # ожидается: Connected + инструмент обнаружен

MCP-серверы обнаруживаются при старте Hermes — после правки конфига нужен рестарт
(рестарт гейтвея согласовывать с владельцем).

## Почему MCP, а не браузер

- Веб-версия Kiwi часто выдаёт абсурдные маршруты (пересадки 20–50 ч, KIV→EDI→FNC).
- `search_flight` отдаёт структурированный отфильтрованный результат с рабочими ссылками.
- Без браузера, без капчи, без ожидания загрузки страниц.
- ВСЕГДА предупреждать пользователя про self-transfer, раздельные билеты и смену аэропорта
  на пересадке.
