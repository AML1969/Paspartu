# Flight Search Patterns

## Cross-reference hub technique

When no direct flight exists and an overnight layover is needed:

1. List all cities with **direct afternoon flights FROM origin** on departure date
2. List all cities with **direct morning flights TO destination** on next day
3. Intersection = viable overnight hubs
