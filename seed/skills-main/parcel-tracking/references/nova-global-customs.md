# Nova Global — маршруты и таможня (ЕС → Украина)

## Типовой маршрут

Для посылок из Западной Европы (Франция, Италия) в Украину через Nova Global:

Франция → Италия → Чехия → Польша → Украина (ЦСС Киев) → отделение

Польша — последняя страна ЕС перед Украиной.

## Таможня: два этапа, НЕ на границе

### 1. Экспортная таможня ЕС (Польша)
- Происходит в Польше при выезде из Евросоюза
- Статус: «Польща. В процесі митного декларування [PL]»
- Быстрая — обычно несколько часов
- После неё посылка едет **под таможенным контролем** напрямую в Киев

### 2. Украинская таможня (Киев, ЦСС)
- ⛔ НЕ на границе. Посылка пересекает границу транзитом.
- Происходит на **ЦСС Киев** (Центральная сортировочная станция, ул. Салютная, 2А)
- Таможенные инспекторы работают прямо на терминале
- Занимает часы, **не дни** (пользователь поправил: «там никогда не бывает таможни двое суток»)
- После таможни — сортировка и доставка в отделение

## Типовые сроки (от выезда из Чехии)

| Этап | Время |
|---|---|
| Чехия → Польша (таможня ЕС) | Несколько часов |
| Таможня ЕС в Польше | Часы |
| Польша → ЦСС Киев (под контролем) | ~12 часов |
| Таможня Украины в ЦСС | Часы |
| Сортировка + доставка в отделение | ~полдня |

**Итого: от выезда из Чехии до отделения в Киеве — 1–2 дня.**

## Контекст (получено от пользователя)

- «Там никогда не бывает таможни двое суток. Обычно она в одни сутки приезжает и уезжает.»
- «Украинская таможня может быть и на терминале новой почты в киеве и поедет под таможенным контролем туда»
- Подтверждено Perplexity: ЦСС на Салютной, 2А — таможня работает прямо там
