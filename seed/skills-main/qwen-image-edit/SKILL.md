# Картинки на fal: Sunburst + Qwen, один скрипт

Один скрипт `scripts/qwen.py`, два режима и два движка. Движок выбирает **скрипт**, а не ты:

| Движок | Эндпоинт fal | Когда берётся |
|---|---|---|
| **OpenAI GPT-Image-2.5 Sunburst** | `openai/gpt-image-2.5/sunburst/edit` · `…/text-to-image` | на фото или в результате есть люди; на картинке должен быть текст; больше 3 исходников |
| **Qwen-Image 2.0** | `fal-ai/qwen-image-2/edit` · `…/text-to-image` (`--pro` → `…/pro/…`) | всё остальное: пейзажи, предметы, животные, интерьеры без людей и без надписей |

Настройка бота лежит в файле `image_engine` в папке профиля: `openai` — всегда Sunburst, `auto` или файла нет — маршрут по таблице, `qwen` — всегда Qwen. Упал основной движок — скрипт сам пробует второй.

**Почему так (проба 11.09.2026):** Qwen в правках с людьми подменяет лица и путает кириллицу («Бабцукин», «сеттибея»). Sunburst сохранил лица и написал весь русский текст без ошибок во всех 8 заданиях. Sunburst дольше (30–40 с против ~10 с) и дороже (~$0.05–0.08 против ~$0.035 за кадр).

## ⛔ Железные правила (нарушение = провал задачи)

1. **Все картинки — только этим скриптом.** Штатный `image_generate` не вызывай: он умеет только Qwen и обходит выбор движка.
2. **Присланное фото — ИСХОДНИК, а не вдохновение.** Есть фото → `edit` с этим файлом. Сгенерировать «похожее» по тексту НЕЛЬЗЯ — пользователь получит чужих людей вместо своих.
3. **Лица и люди неприкосновенны.** Скрипт сам добавляет в промпт фразу сохранения лиц; ничего не подменяй и не дорисовывай без прямой просьбы.
4. **Несколько фото — передавай все:** `--image A --image B`. «Перенеси его с этого фото на то», «объедини кадры», «поставь их рядом» — это ОДИН вызов со всеми исходниками.
5. **Никаких ссылок `fal.media` / `v3.fal.media` в ответе** — Telegram их не грузит. Отдавай значение поля `telegram` (`MEDIA:/абс/путь`) КАК ЕСТЬ.
6. **Не дёргай fal своим curl-ом** — только этот скрипт: он жмёт фото, выбирает движок, качает результат, сам достаёт ключ.
7. Перед вызовом — короткая квитанция: «🎨 Рисую…» / «🖌️ Редактирую…». Картинка занимает от 10 секунд до полутора минут.
8. `--engine openai|qwen` ставь, только если пользователь прямо назвал модель. Модель в ответе не называй, если не спросили.

## Разбор задачи ПЕРЕД вызовом

1. **Перечитай задачу дословно.** Какие фото даны и какую роль играет каждое: откуда берём объект, куда вставляем, что должно остаться.
2. **Сформулируй себе:** ЧТО меняем и ЧТО остаётся неизменным (лица, люди, поза, одежда, фон, композиция, свет).
3. **Не знаешь фактуру — сначала найди** (место, форма, логотип, марка машины, эпоха): `--research «что уточнить»` или свой веб-поиск.
4. **Вызови скрипт со ВСЕМИ фото** и отдай результат через `MEDIA:`.

Если пользователь говорит «не то» — не начинай с нуля: уточни, что именно не так, и сделай ОДНУ следующую правку от последнего результата.

## Использование — основной путь `--raw`

Отдай скрипту **дословный запрос пользователя** и все фото. Дальше он делает сам:
исходники → **vision-описание каждого фото** (gpt-5.4) → *(по желанию)* **факты из интернета** (Perplexity) →
**промпт + оценки** (DeepSeek) → **выбор движка** → **авто-параметры** → **картинка вместе с фотографиями**.

**Автопромптинг (14.09.2026, по гайду OpenAI для GPT-Image-2.5).** DeepSeek возвращает не одну строку, а план:
короткий промпт для Qwen **и** помеченные секции для Sunburst — `Task` (одно изменение, «Change only…»),
`Subject` (роль каждого исходника: image 1 — subject, image 2 — background, image 3 — clothing),
`Composition`, `Style and rendering` (материалы, свет, оптика), `Text` (надписи дословно в кавычках,
кириллица дополнительно продиктована по буквам: `Бабушкина = Б-А-Б-У-Ш-К-И-Н-А`), `Preserve exactly`
(фраза сохранения лиц), `Avoid`. Нет текста на картинке — в промпт уходит явное «No text anywhere».

Он же подбирает параметры вызова, и каждый перебивается флагом:

| Параметр | Авто | Флаг |
|---|---|---|
| `quality` | текст на картинке → `xhigh`, иначе `high` | `--quality` |
| `background` | «логотип/стикер/без фона/прозрачный» → `transparent` + `png` | `--background` |
| `image_size` | сторис/афиша/баннер/аватар → подходящая форма кадра | `--size` |

Размер для Sunburst подгоняется под лимиты модели (сторона кратна 16 и ≤3840, соотношение ≤3:1,
0.66–8.29 Мпикс) — кривой размер больше не роняет вызов в 422. Если fal всё же ответил 422 на
дополнительных параметрах, скрипт повторяет тот же движок без них и только потом уходит на запасной.

```bash
# правка / слияние — порядок фото задаёт роли image 1, image 2, …
python3 <папка скилла>/scripts/qwen.py edit \
  --image "/абс/фото1.jpg" --image "/абс/фото2.jpg" \
  --raw "перенеси мальчика со второго фото на первое, чтобы они стояли рядом, и замени фон на набережную"

# нужна фактура, которой ты не знаешь
python3 .../qwen.py edit --image "/абс/фото.jpg" \
  --raw "одень его в форму пилота Lufthansa" --research "как выглядит форма пилота Lufthansa"

# с нуля
python3 .../qwen.py generate --raw "постер «Ночь джаза в Одессе», 20 сентября, 19:00" --size portrait_4_3
```

Опции: `--raw` · `--image` (повторяется: Qwen до 3, Sunburst до 16) · `--prompt` (готовый английский промпт, если уверен) · `--context "факты"` · `--research "что уточнить"` · `--engine openai|qwen|auto` · `--pro` (для Qwen) · `--quality low|medium|high|xhigh|max` (для Sunburst, по умолчанию авто: high, а с текстом xhigh) · `--background transparent|opaque|auto` · `--size square_hd|portrait_4_3|landscape_16_9|…|1024x1536` (по умолчанию форма кадра подбирается по запросу) · `--num 1..4` · `--format png|jpeg` · `--dry-run` (собрать промпт и показать выбранный движок, не рисуя).

Скрипт печатает JSON: `image` (путь), **`telegram`** (`MEDIA:/путь` — вставить как есть), `engine` (какой движок сработал), `route` (почему), `fallback` (если основной движок упал), `prompt_used`, `prompt_source`, `params` (quality/background/size для Sunburst), `endpoint`, `build_s`, `elapsed_s`.
`--dry-run` дополнительно показывает `prompt_qwen` (короткая версия) и `params.*_why` — почему выбран каждый параметр.

## Правила промпта (если собираешь `--prompt` сам)

Свой `--prompt` отключает автопромптинг целиком: секции, спеллинг кириллицы и авто-параметры не соберутся.
Для Sunburst пиши промпт теми же помеченными секциями (Task / Subject / Composition / Style / Text /
Preserve exactly / Avoid), для Qwen — одной плотной строкой.

1. **Английский**, но текст, который должен появиться на картинке, — дословно на языке пользователя в двойных кавычках: `Add a sign that reads "Хлеб · Молоко"`.
2. **Начинай с глагола действия:** `Replace…`, `Remove…`, `Add…`, `Change…`, `Take … and place …`.
3. **Одно изменение за вызов.** Три правки — три последовательных вызова от результата предыдущего.
4. **Нумеруй исходники:** `image 1`, `image 2`.
5. **Фотореализм ≠ illustration.** Для реальных фото: `photorealistic photo, genuine camera shot, natural lighting, sharp focus`.
6. **Анатомию не правь редактированием** («сделай пропорции правильными») — честно скажи и предложи сгенерировать заново.

## Грабли

- **«Он нарисовал других людей»** — значит фото не ушло на вход (сработал `image_generate`) или картинка ушла в Qwen мимо маршрута. Смотри поля `engine` и `route`.
- **Схемы полей разные:** Qwen знает ровно prompt, image_urls, image_size, num_images, output_format; Sunburst — плюс quality и background. Лишнее fal вернёт как 422 — скрипт шлёт каждому только его поля.
- **Лимит времени.** У терминала бота 180 с: скрипт укладывает сборку промпта, основной движок и запасной в 165 с. Квитанция перед вызовом обязательна.
- **Ключ.** Скрипт сам берёт `FAL_KEY` из окружения или `.env` профиля. Ключ fal общий на троих ботов.
- **Фото из Telegram** приходит сжатым — для правки хватает. Файл >20 МБ бот скачать не может, проси прислать как фото или ссылкой.
- **Цена** ~$0.035 (Qwen) – $0.08 (Sunburst) за картинку — разрешения на каждый запуск не спрашивай.
